# Release v0.2.0

## Summary

This version is the first tagged release of the toolkit. It gathers the networks, losses, training loops, and metrics that had accumulated in the repository into the `dlk` package, whose name dates from shortly before this tag, when the directory `dlkit` was renamed.

An application importing `dlk` at this point gets training loops for feed-forward networks and GANs, with checkpointing, learning-rate schedulers, transform hooks for inputs and targets, and a profiler that wraps the same loops. The network library covers MLPs and MLPResNets with optional attention, 1D and 2D convolutional networks with residual connections, UNets in both dimensions, encoder and decoder nets derived from them, autoencoders, EfficientNet, and transformers for time-series and channel-wise inputs. GAN training is served by Wasserstein, hinge, and least-squares losses, with several gradient-penalty variants for Wasserstein critics. `dlk.metrics` computes Wasserstein distance, maximum mean discrepancy, and Sinkhorn divergence.

The changelog in these notes folds 123 commits into one bullet per capability, since no earlier release exists to diff against.

## Changelog

### Features

- 0c6a70e nets: MLP and MLPResNet models, with attention layers, fiber-wise linear layers, optional spectral norm, and forward passes over multiple input tensors
- d1049c0 nets: 1D and 2D convolutional networks, including ConvResNet and a universal multi-level block, with configurable normalization
- 2facb27 nets: UNets for 1D and 2D data, and encoder and decoder nets derived from them
- 3010e3c nets: EfficientNet and transformer architectures, the latter for time-series inputs and for channel-wise embedding with channel-wise attention
- 6cdd0f9 nets: utility functions that count and print model parameters
- 2e987b4 opt: training loops for feed-forward networks and GANs, including the interplay between discriminator and generator optimization steps
- e1e36d0 opt: NaN loss handling and a user-supplied validation callback in the training loop
- 0c389f8 opt: checkpointing during and after training
- 9de09b0 opt: learning-rate schedulers, used from the training loops
- 2a48011 opt: a profiler that runs the training functions under measurement
- e2d59e1 opt: transform functions for inputs and targets
- 27f524d loss: GAN losses in Wasserstein, hinge, and least-squares form
- 57ea2d8 loss: gradient penalties for Wasserstein critics, split into a Lipschitz-only penalty and an optimal potential penalty
- 5abffcf metrics: Wasserstein distance, maximum mean discrepancy, and Sinkhorn divergence
- eea768a log: logging to files and to stdout/stderr, with a filter for matplotlib's own messages

### Bug fixes

- fef15e8 nets: padding and skip-connection sizes in the 1D convolutional multi-level block for kernel sizes above 3
- 575a5fc nets: flattening of multiple inputs in the MLP, and passing a dictionary as kwargs
- 971fab6 opt: logging in GAN training, including the case of a regularization term set to None
- 5ccb056 opt: profiler writing table and trace files into a directory that does not exist yet
- 0a0c360 opt: handling of the maximum number of batches

### Refactorings

- c0f69ba rename the package directory `dlkit` to `dlk`
- 8e91c6c opt: simplify the training routines and split them by network type
- dd1627e opt: drop the `vmap` call from GAN training and leave vmapping to the network's forward function
- 0dff4ff nets: remove the repetition in layer initialization

### Documentation

- 1cdbd35 docs: README covering the package and its use
- be25154 docs: exploratory documents on neural-net training and noise injection
- 718ab5c docs: rename the agent instructions file from WARP to AGENTS

### Build and CI

- 8733598 build: make the package installable, and settle the `docs` directory name
