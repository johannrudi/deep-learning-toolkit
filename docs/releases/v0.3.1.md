# Release v0.3.1

## Summary

This version changes nothing an application can observe. It follows v0.3.0 by a day and prepares the repository for being public: the README was corrected and rewritten in places, and the CI workflows moved to Node.js 24, ahead of GitHub Actions deprecating Node 20.

## Changelog

### Documentation

- b3c05ba docs: correct the text and typos in the README for the public repository

### Build and CI

- 544d9b7 ci: use Node.js 24 in the workflows, ahead of the Node 20 deprecation
- 889a714 ci: rename the `test` workflow to `tests`
- 31594a8 minor renaming
