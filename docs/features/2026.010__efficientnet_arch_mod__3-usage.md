# Configurable Network Styles for the 1D EfficientNet

`ScalableEfficientNet1D` and its 20 named variants (`dlk/nets/efficientnet1d.py`) now take a **style**: the normalization at each position, the convolution biases, a pre-norm, a residual scale, and spectral normalization, set once for the whole network. The default style builds the paper's EfficientNet, with the same modules, `state_dict` keys, and outputs as before.

The styles exist for critics. With `BatchNorm1d` after every convolution, spectral normalization changes nothing in the convolutional body (`docs/features/2026.009__efficientnet_spectral_norm__2-usage.md`). The `NET_*SN*` presets move the normalization to the block input, so spectral normalization binds in every branch.

## Configs and styles

Two kinds of frozen dataclasses describe a network:

- A **config** holds sizes and layout, which differ per variant or stage: `MBConvConfig`, `StageConfig`, `StemConfig`, `HeadConfig`.
- A **style** holds design choices that are the same for every block: `MBConvStyle`, `FusedMBConvStyle`, `StemStyle`, `HeadStyle`, bundled in `NetStyle`.

Every named variant takes `stem`, `head`, and `style`:

```python
from dlk.nets.efficientnet1d import NET_EXACT_SN_FLOORED_PRE_GN, EfficientNetV2BB0, HeadConfig

critic = EfficientNetV2BB0(
    input_channels=1,
    input_length=128,
    num_classes=1,
    block_dropout=0,
    head=HeadConfig(dropout=0),
    style=NET_EXACT_SN_FLOORED_PRE_GN,
)
```

`stem=None` or `head=None` replaces that part by `nn.Identity()`. With `head=None`, the head style is ignored, pre-norm included.

Each convolution gets one `ConvNorm(normalization, bias)`: its bias and the normalization after it. `CONV_NORM_BATCH = ConvNorm(nn.BatchNorm1d, bias=False)` is the default, and `CONV_NORM_NONE = ConvNorm(None, bias=True)` drops the normalization and lets the bias take over its role. The style fields are:

- `MBConvStyle`: `pre_normalization` at the block input, `expand_conv_norm`, `depthwise_conv_norm`, `project_conv_norm`;
- `FusedMBConvStyle`: `pre_normalization`, `fused_conv_norm`, `project_conv_norm`;
- `StemStyle` and `HeadStyle`: `conv_norm`, and for the head also `pre_normalization`.

`expand_conv_norm` and `project_conv_norm` are ignored where a block has no such convolution (`expand_ratio == 1`), so one style serves every stage. A block with a residual computes `skip_scale * (x + f(N(x)))`, where `N` is the pre-norm; the identity path stays unnormalized.

## The presets

`GN` is `partial(nn.GroupNorm, 1)`: one group, i.e., normalization over channels and length per sample.

| Preset | Stem | Blocks (pre / convs) | Head (pre / conv) | `skip_scale` | SN | Depthwise SN | GN `eps` | `dropout_mode` |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `NET_BASELINE` | `CONV_NORM_BATCH` | none / `CONV_NORM_BATCH` | none / `CONV_NORM_BATCH` | 1.0 | off | n/a | n/a | `"dropout"` |
| `NET_SN_PRE_GN` | `CONV_NORM_NONE` | GN / `CONV_NORM_NONE` | GN / `CONV_NORM_NONE` | 0.5 | on | C0 | 1e-5 | `"drop_path"` |
| `NET_SN_FLOORED_PRE_GN` | `CONV_NORM_NONE` | GN / `CONV_NORM_NONE` | GN / `CONV_NORM_NONE` | 0.5 | on | C0 | 1e-4 | `"drop_path"` |
| `NET_EXACT_SN_PRE_GN` | `CONV_NORM_NONE` | GN / `CONV_NORM_NONE` | GN / `CONV_NORM_NONE` | 0.5 | on | C2 | 1e-5 | `"drop_path"` |
| `NET_EXACT_SN_FLOORED_PRE_GN` | `CONV_NORM_NONE` | GN / `CONV_NORM_NONE` | GN / `CONV_NORM_NONE` | 0.5 | on | C2 | 1e-4 | `"drop_path"` |

When to use which:

- `NET_BASELINE` is `NetStyle()`, the paper's network and the default of every variant. Use it for classifiers and stems that train in batches.
- The `NET_*SN*` presets are for critics with a Lipschitz target. They differ in two independent settings, so the pairs isolate each effect:
    - C2 (`NET_EXACT_SN_*`) in place of C0 (`NET_SN_*`) for the depthwise convolutions;
    - a floored pre-norm (`*_FLOORED_*`), `eps = 1e-4`, which bounds the GN gain by $\max\lvert\gamma\rvert / 0.01$.
- Start with `NET_EXACT_SN_FLOORED_PRE_GN`, which has the tightest per-layer bounds and, of the two floored presets, keeps the most signal at initialization. The others are for ablations.

The four `NET_*SN*` presets come from one private function, so there is no public builder; derive other variants with `dataclasses.replace` (see below).

## Dropout and drop path

`block_dropout` sets the largest residual-branch rate, ramped linearly from 0 over the blocks. `NetStyle.dropout_mode` chooses what the rate does:

- `"dropout"` (default, and the mode of `NET_BASELINE`): element-wise `nn.Dropout` on the branch output. Blocks without residual ignore it, as before.
- `"drop_path"` (the mode of the four `NET_*SN*` presets): stochastic depth. In train mode, a block drops a sample's whole branch with probability $p$ and scales kept branches by $1/(1-p)$. Blocks without residual get neither.

`HeadConfig(dropout=...)` sets the dropout before the classifier.

**A critic turns both off**, with `block_dropout=0` and `HeadConfig(dropout=0)`. Either kind makes the critic random in train mode, so the critic evaluations within one gradient or finite-difference penalty see different networks. The presets do not set these, because they are arguments of the network, not styles.

## Building a custom style

Styles are frozen; derive new ones with `dataclasses.replace`:

```python
from dataclasses import replace

from dlk.nets.efficientnet1d import CONV_NORM_NONE, NET_BASELINE, NET_SN_PRE_GN

# today's network, with C0 on every convolution and linear layer
sn_baseline = replace(NET_BASELINE, enable_spectral_norm=True)

# NET_SN_PRE_GN with a variance-preserving residual sum and element-wise dropout in place of drop path
skip_scale = 2**-0.5
sn_pre_gn_dropout = replace(
    NET_SN_PRE_GN,
    mbconv=replace(NET_SN_PRE_GN.mbconv, skip_scale=skip_scale),
    fused=replace(NET_SN_PRE_GN.fused, skip_scale=skip_scale),
    dropout_mode="dropout",
)

# NET_BASELINE without the normalization after the MBConv projection
gn_no_project_norm = replace(
    NET_BASELINE,
    mbconv=replace(NET_BASELINE.mbconv, project_conv_norm=CONV_NORM_NONE)
)
```

`skip_scale = 1` is the plain residual sum, `0.5` the average, and $1/\sqrt{2}$ preserves the variance of two independent branches. Two styles built from separately created `partial`s compare unequal, because `functools.partial` compares by identity; compare the built networks instead.

A style applies to every block. Different styles per stage need blocks built by hand. A custom `block_cls` in a `StageConfig` must subclass `MBConv1D` or `FusedMBConv1D` and accept `style` and `enable_spectral_norm`, in this order after `config`; otherwise `NetStyle.for_block` raises `TypeError`.

Invalid values raise `ValueError` at construction, e.g., a non-positive `skip_scale` or a `drop_path` rate on a block without residual.

## C0 and C2

With `enable_spectral_norm=True`, every convolution and linear layer is normalized with C0, except the depthwise convolutions under C2.

- **C0** is PyTorch's `spectral_norm`: it divides the weight by $\sigma$ of the reshaped `(out, in * k)` kernel matrix. A 1×1 convolution and a linear layer are then at most 1-Lipschitz, a convolution with kernel size $k$ at most $\sqrt{k}$-Lipschitz. For a depthwise convolution with $C > k$ channels, the matrix $\sigma$ overestimates the operator norm, so C0 shrinks the layer more than needed: at orthogonal initialization each filter has norm about $\sqrt{k/C}$.
- **C2** (`MBConvStyle(depthwise_spectral_norm="exact")`) applies only to the depthwise convolutions of `MBConv1D`. `DepthwiseSpectralNorm` (`dlk/nets/spectral_norm.py`) divides the whole weight by one scalar, the largest DFT magnitude over all channels' filters, zero-padded to 64 points. The channels keep their relative gains. The operator norm is exactly 1 with circular padding at length 64, and at most $1/(1 - (k-1)\pi/64)$ otherwise: about 1.11 for $k = 3$ and 1.24 for $k = 5$. C2 has no power iteration, so it is exact after every optimizer step. It costs one `rfft` of a `(C, 64)` tensor per forward, also in eval mode.

## Choosing $\tau$ through `eps`

GroupNorm divides by $\sqrt{\mathrm{var} + \epsilon}$, so `eps` $= \tau^2$ floors the denominator at $\tau$, and the pre-norm's gain is at most $\max\lvert\gamma\rvert / \tau$. A large $\tau$ gives a tight bound, but it also kills the signal.

The rule: the stream keeps its scale only if $\tau \lesssim c$, the gain of the branch of a block without residual at initialization. The expansion, two SiLUs, the SE gate, and C0's contraction of the depthwise filters multiply to $c \approx 0.013$ for C0 and $0.02$ for C2. The block output is about $c \cdot r / \sqrt{r^2 + \tau^2}$ for an input of RMS $r$, so below the floor, $r \ll \tau$, the block gain saturates at $c/\tau$ instead of growing as $c/r$.

- $\tau = 1$: every block without residual shrinks the stream about 100×, and the network output at initialization is about $10^{-12}$.
- $\tau = 0.1$: the stream still decays geometrically.
- $\tau = 0.01$, the floored presets: the block gain at input RMS 0.01 is about 1 (0.95 for C0, 1.47 for C2), the output at initialization is within 1 to 1.5 decades of the unfloored presets, and the per-block bound is 60 to 270.

The plan's Addendum, Step 7, has the per-layer trace and the measured gains.

For another floor, replace the pre-norm of a preset by a GroupNorm with `eps` $= \tau^2$:

```python
from dataclasses import replace
from functools import partial

import torch.nn as nn

from dlk.nets.efficientnet1d import NET_EXACT_SN_PRE_GN

pre_norm = partial(nn.GroupNorm, 1, eps=0.02**2)  # tau = 0.02
base = NET_EXACT_SN_PRE_GN
style = replace(
    base,
    mbconv=replace(base.mbconv, pre_normalization=pre_norm),
    fused=replace(base.fused, pre_normalization=pre_norm),
    head=replace(base.head, pre_normalization=pre_norm),
)
```

Stay at or below $c$; the signal propagation example shows the effect.

## What the styles bound

For a `NET_*SN*` block without SE, the Lipschitz constant is at most

$$\text{skip\_scale} \cdot \left(1 + L_\text{branch} \cdot \max\lvert\gamma\rvert / \tau\right),$$

where $L_\text{branch}$ multiplies the per-layer bounds: $\sqrt{k}$ for a C0 convolution, the cap above for C2, and 1.0998 for each SiLU. The empirical Lipschitz example finds every estimate at least about 10× below this bound.

The styles bound the convolutions, not the network. Three gaps are left to the penalties of plan 2026.008:

- **The SE gate.** $x \cdot \mathrm{sigmoid}(f(\mathrm{mean}(x)))$ has a derivative that grows with $\lvert x\rvert$, so blocks with SE have no global bound. All presets keep SE.
- **GroupNorm's $\gamma$** is learnable and unbounded, and so is the bound above.
- **C0 lags the optimizer.** Its estimate $u^\top W v$ can only underestimate $\sigma$, so the normalized weight drifts slightly above 1 during training. Orthogonal initialization gives near-equal top singular values, so the power iteration, one step per training forward, converges slowly. This happens with `replace(NET_BASELINE, enable_spectral_norm=True)` too. C2 stays at exactly 1. The plan's Addendum, Step 9, has the numbers.

`NET_BASELINE` bounds nothing: a normalization after a convolution removes the spectral normalization's scale.

## Migration

The old network arguments are gone. A critic before and after:

```diff
-from dlk.nets.efficientnet1d import EfficientNetV2BB0
+from dlk.nets.efficientnet1d import EfficientNetV2BB0, HeadConfig, NET_EXACT_SN_FLOORED_PRE_GN

 EfficientNetV2BB0(
     input_channels=input_channels,
     input_length=input_size,
     num_classes=output_size,
-    dropout_connect=dropout,
-    dropout_head=dropout,
+    block_dropout=0,
+    head=HeadConfig(dropout=0),
+    style=NET_EXACT_SN_FLOORED_PRE_GN,
 )
```

| Before | After |
| --- | --- |
| `enable_spectral_norm=True` | `style=replace(NET_BASELINE, enable_spectral_norm=True)` for the old behavior, or a `NET_*SN*` preset |
| `dropout_connect=p` | `block_dropout=p` |
| `dropout_head=p` | `head=HeadConfig(dropout=p)` |
| `stem_channels=c`, `head_channels=c` | `stem=StemConfig(channels=c)`, `head=HeadConfig(channels=c)` |
| `enable_stem=False`, `enable_head=False` | `stem=None`, `head=None` |
| `StageSpec(block_cls, MBConvConfig(..., num_layers=n))` | `StageConfig(block_cls, MBConvConfig(...), num_blocks=n)` |
| `stage_specs=`, `net.stage_specs` | `stage_configs=`, `net.stage_configs` |
| `config._replace(...)` | `dataclasses.replace(config, ...)` |
| `MBConv1D(config, dropout)` | `MBConv1D(replace(config, dropout=p))` |
| `from dlk.nets.utils import set_spectral_norm` | `from dlk.nets.spectral_norm import set_spectral_norm` (also `get_spectral_norm`) |

A standalone block takes its rates in the config, then its style, then the spectral normalization flag:

```python
from dlk.nets.efficientnet1d import NET_SN_PRE_GN, MBConv1D, MBConvConfig

config = MBConvConfig(kernel_size=3, stride=1, expand_ratio=4, input_channels=8, output_channels=8, se_ratio=0.25, drop_path=0.1)
block = MBConv1D(config, style=NET_SN_PRE_GN.mbconv, enable_spectral_norm=True)
```

Pass `style` and `enable_spectral_norm` by keyword: `MBConv1D` and `FusedMBConv1D` take `style` before `enable_spectral_norm`.

A standalone block keeps PyTorch's default initialization; only `ScalableEfficientNet1D` initializes its layers.

## Checkpoints

A checkpoint loads only into a network with the same layout. The style changes the keys: removed normalizations, convolution biases, pre-norm weights, and the spectral normalization parametrizations. For the stem and one depthwise convolution of `EfficientNetV2BB0`:

```text
NET_BASELINE:            stem.0.weight
                         stem.1.{weight, bias, running_mean, running_var, num_batches_tracked}
                         blocks.4.depthwise_conv.0.weight
                         blocks.4.depthwise_conv.1.{weight, bias, running_mean, ...}
NET_SN_PRE_GN:           stem.0.bias
                         stem.0.parametrizations.weight.{original, 0._u, 0._v}
                         blocks.4.pre_norm.{weight, bias}
                         blocks.4.depthwise_conv.0.bias
                         blocks.4.depthwise_conv.0.parametrizations.weight.{original, 0._u, 0._v}
NET_EXACT_SN_PRE_GN:     as NET_SN_PRE_GN, but blocks.4.depthwise_conv.0.parametrizations.weight.original only
```

A mismatch raises `RuntimeError: Error(s) in loading state_dict for EfficientNetV2BB0: Missing key(s) ...`. Rebuild the network with the style it was trained under.

One case does not raise: `eps` is not stored, so a floored and an unfloored preset with the same depthwise normalization have the same keys. A checkpoint of `NET_SN_FLOORED_PRE_GN` loads silently into `NET_SN_PRE_GN`, and computes a different function. Record the preset with the checkpoint.

The default style keeps the old keys, so old `NET_BASELINE` checkpoints load unchanged. Neither `block_dropout` nor `dropout_mode` changes the keys.

## Running the examples

Both examples compare the six presets on `EfficientNetV1BB0` and `EfficientNetV2BB0` at initialization, on CPU; the run times below are on 16 cores. The figures go to the output directory, the current directory by default.

```sh
uv run python examples/nets/efficientnet_signal_propagation.py [output_dir]
uv run python examples/nets/efficientnet_empirical_lipschitz.py [output_dir] [--quick]
```

- `efficientnet_signal_propagation.py` (about 3 s) plots, per block, the mean squared activation and the channel-mean squared of the residual stream ([Brock et al., 2021a]). It writes `signal_propagation_<network>.png`. `NET_BASELINE` stays near 1; the `NET_*SN*` presets drop to about $10^{-4}$ at the first MBConv block without residual and then decay slowly, the C2 presets least.
- `efficientnet_empirical_lipschitz.py` (about 50 s; `--quick` about 15 s) estimates the Lipschitz constant from below, per block and for the whole network, by input-gradient norms and finite-difference quotients on sums of radial basis functions. It plots the bound above for the SE-free blocks of the floored presets. It writes `lipschitz_blocks_<network>.png` and `lipschitz_networks.png`, and logs a warning if an estimate exceeds its bound.
